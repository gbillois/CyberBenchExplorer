Avertissement de confidentialité et autorisation LLM
L’utilisation d’un LLM et des fournisseurs configurés doit être explicitement autorisée par l’organisation évaluée. Les données d’entretien et certaines informations du questionnaire seront transmises aux fournisseurs sélectionnés.

1. API de transcription

OpenAI utilise gpt-4o-transcribe-diarize jusqu’à 25 Mo. Au-delà, Helper bascule vers Azure Speech si une clé Azure est configurée. Azure Fast Transcription accepte jusqu’à 250 Mo et moins de 2 heures.

2. API d'analyse et de vérification

Modèle d’analyse

Les données sont envoyées au fournisseur configuré. Les clés restent uniquement en mémoire.
Pour garantir une qualité suffisante, utilisez au minimum GPT-5.5 ou Claude Opus 4.6, ou une version supérieure.

Modèle de Check & Challenge

Le modèle de contradiction peut utiliser un fournisseur ou modèle différent.
